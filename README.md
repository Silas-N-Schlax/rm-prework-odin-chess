# Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/Silas-N-Schlax/rm-prework-odin-chess.git
```

Navigate to the project directory:

```bash
cd rm-prework-odin-chess
```

Bundle
```bash
bundle install
```

Run `ruby test.rb` in your terminal.
